# YT‑MP3

אפליקציית **PWA** להורדת אודיו מיוטיוב כ‑MP3. הממשק סטטי, מותאם מובייל, ורץ ב‑GitHub Pages.
ההמרה עצמה מתבצעת ע"י שרת קטן שעוטף את **yt‑dlp** (החבילה המקורית) — כי דפדפן לבדו לא יכול להוריד ולקודד אודיו מיוטיוב.

```
web/      ← ה‑PWA (זה מה שעולה ל‑GitHub Pages)
server/   ← גשר yt-dlp (FastAPI). מריצים מקומית / Docker / Cloud Run
tools/    ← יצירת האייקונים
```

## מה יש באפליקציה

- שדה קישור עם **הדבקה בלחיצה** וזיהוי אוטומטי של הכתובת מתוך טקסט משותף
- **שיתוף ישיר מיוטיוב** לאפליקציה (Web Share Target) — ההורדה מתחילה לבד
- תצוגה מקדימה: תמונה ממוזערת, שם, ערוץ ואורך
- בחירת איכות: 128 / 192 / 256 / 320 kbps (נשמרת למכשיר)
- התקדמות חיה מהשרת (SSE, עם נפילה לפולינג אם יש פרוקסי שמאגר)
- היסטוריה מקומית של 12 ההורדות האחרונות
- עובד אופליין כשלד אפליקציה, מותקן למסך הבית, תמיכה בכהה/בהיר ו‑RTL

## הפעלה מהירה

### 1. השרת

```bash
cd server
./run.sh            # יוצר venv, מתקין תלויות ומרים על פורט 8000
```

דורש **ffmpeg** מותקן (`brew install ffmpeg` / `sudo apt install ffmpeg`).

עם Docker:

```bash
docker build -t ytmp3 server
docker run --rm -p 8000:8000 ytmp3
```

### 2. האפליקציה

פותחים את כתובת ה‑Pages, נכנסים ל‑⚙︎ **הגדרות**, מזינים את כתובת השרת ולוחצים **בדיקת חיבור**.

## חשוב: איך מחברים את הנייד לשרת

דף ב‑GitHub Pages מוגש ב‑HTTPS, ולכן הוא **לא יכול** לפנות לשרת ב‑`http://` על כתובת רשת מקומית
(הדפדפן חוסם תוכן מעורב). האפשרויות:

| דרך | מתאים ל | הערות |
|---|---|---|
| `http://localhost:8000` | דפדפן על אותו מחשב | מותר כחריג; השרת שולח גם את כותרת ה‑Private Network Access |
| מנהרה — `cloudflared tunnel --url http://localhost:8000` או `ngrok http 8000` | נייד, בלי לפרוס כלום | מקבלים כתובת HTTPS זמנית ומדביקים בהגדרות |
| Cloud Run / Fly / Render | שימוש קבוע מהנייד | HTTPS קבוע |
| **Firebase Hosting + Cloud Run** | הכי נקי | אותו origin — בלי CORS, בלי הגדרות באפליקציה |

### מסלול Firebase (מומלץ לנייד)

`firebase.json` שבריפו כבר מכוון: את `web/` הוא מגיש כאתר, ואת `/api/**` הוא מנתב לשירות Cloud Run בשם `ytmp3-bridge`.
האפליקציה מזהה שרת באותו origin לבד — אין מה להגדיר.

```bash
gcloud run deploy ytmp3-bridge --source server --region us-central1 --allow-unauthenticated --memory 1Gi --timeout 900
firebase deploy --only hosting
```

## פריסה ל‑GitHub Pages

ב‑**Settings → Pages** בוחרים `Source: GitHub Actions`. כל דחיפה ל‑`main` שנוגעת ב‑`web/` מפרסמת מחדש.

## משתני סביבה לשרת

| משתנה | ברירת מחדל | תפקיד |
|---|---|---|
| `PORT` | `8000` | פורט האזנה |
| `ALLOWED_ORIGINS` | `*` | רשימת origins מורשים ל‑CORS |
| `JOB_TTL_SECONDS` | `1800` | כמה זמן קובץ נשמר לפני מחיקה |
| `MAX_DURATION_SECONDS` | `0` (ללא הגבלה) | חסימת סרטונים ארוכים |
| `YTDLP_COOKIES_FILE` | — | קובץ cookies, אם יוטיוב מבקש אימות |
| `YTDLP_PROXY` | — | פרוקסי ל‑yt‑dlp |

> בענן יוטיוב לפעמים חוסם כתובות IP של דאטה‑סנטרים ומבקש אימות. אם זה קורה, מייצאים cookies מהדפדפן
> ומצביעים עליהם עם `YTDLP_COOKIES_FILE`, או מריצים את השרת מהבית דרך מנהרה.

## שיתוף מיוטיוב לאפליקציה

מתקינים את ה‑PWA למסך הבית (Chrome → *הוספה למסך הבית*), ואז ביוטיוב **שיתוף → YT‑MP3**.
זה מבוסס על Web Share Target, שנתמך ב‑Android; ב‑iOS אין עדיין תמיכה, ושם משתמשים בהדבקת הקישור.
